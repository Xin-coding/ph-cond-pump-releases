# PH Cond Pump — Windows 便携版

pH、电导率与有限剂量注射泵控制工作台，中文界面。

**[下载最新正式版](https://github.com/Xin-coding/ph-cond-pump-releases/releases/latest)**

在 Releases 的 Assets 中下载 `PHCondPump-版本号-windows-x64.zip`，完整解压后运行 `PHCondPump.exe`，无需另装 Python 或登录 GitHub。不要下载 GitHub 自动生成的 Source code ZIP，它只是这个说明仓库。

本仓库只发布编译程序、说明和仿真示例。开发源码仓库保持私有；安装包不含真实实验、个人校准或运行配置，软件不会上传实验数据。

## v1.5.3：泵速率与连续测试修复

修复新体积沿用旧注射时间导致注射过快的问题：先设置体积，在停止状态刷新流量，启动前联合核对体积、速率和泵内时间。相同速率连续测试也会刷新时间。停止后等待最终累计量稳定，避免误判剂量不足；测试页显示锁定原因并提供原位核实与恢复。

247 项自动检查通过。实机连续两次 0.50 mL / 10 mL/min，停止读回用时约 3.266、3.281 秒，泵端累计量均增加 0.500 mL；未称量实际收集量。

## v1.5.2：一键更新与空闲自动安装

点击“一键更新并重启”即可连续检查、下载、验证和安装。也可开启自动下载、空闲且设备断开后的自动安装：实验、泵任务、连接或弹窗未结束时等待；安装前显示可取消的 30 秒倒计时。更新不会强制结束实验、断开泵或在重启后恢复注射。

安装包按版本命名，保存在当前数据根目录的 `updates/安装包`。页面显示完整路径并提供“打开安装包文件夹”，重启后也能找到。保留“仅下载安装包”供另一台电脑使用，以及离线导入。

## 注射泵与 pH 信号处理

修复 10 mL/min 流量参数被仪器拒绝的问题；单次定量等待泵端目标结束，并保留有界超时保护。目标量、计时估算和泵端计量分别显示；提前停止或计量矛盾会标记“剂量待核实”，要求核对实际余量后再继续自动注射。STOP 测试分别判定停止控制响应和剂量可信度。

独立的实验前泵测试不需要 pH、电导率或启动实验。正式泵参数收敛为单次量、速率、推力、可用总量与混合等待；启动前确认仪器校正和注射器信息。测试参数与正式实验分别保存，测试消耗仍扣减实际余量。

pH 增加异常点门控、控制平滑与独立显示平滑，原始数据完整保留；支持暂停后修改目标、线性 OH⁻ 估算切换，以及旧实验离线处理预览。首次升级重新核对仪器信息与实际余量，旧软件校准系数不再叠加。

旧版（含本地预览）在“版本与更新”检查、下载并安装 v1.5.3 后，即可使用新流程。默认每天自动检查，自动下载和安装需用户开启。安装前结束实验、确认停泵并断开；数据与校准、余量、导出保持保留。本地预览继续使用自己的独立数据目录。首次启动可能提示历史剂量需核实。

详细变更见 [v1.5.3 发布说明](https://github.com/Xin-coding/ph-cond-pump-releases/releases/tag/v1.5.3)。实机参数写入、泵端定量结束和主动 STOP 响应已有通信验证；实际收集液体的体积精度尚未独立测量，推力保护仍需现场验收。

## 升级

在软件“版本与更新”检查和下载，也支持通过 U 盘导入官方 ZIP。安装前结束实验、确认泵停止并断开。更新器验证发布签名及文件校验，备份后使用数据库副本检查新版启动，再替换程序。

v1.4.0 起只支持升级到更高版本，取消主动版本回退，拒绝降级和同版重复安装。安装中断时仍能修复当前未完成的安装；修复不用于回退已完成升级，不覆盖当前实验数据、校准或注射器余量。重启不会自动连接或恢复加液。

首次使用将完整 ZIP 解压到新的可写文件夹。数据默认仍在当前 Windows 用户桌面的 `PH-Cond-Pump/data`；若指定过 `PHCOND_HOME`，沿用指定目录。在“版本与更新”核对实际程序和数据目录，不要同时运行新旧程序。

## 单次实验导出与恢复

1. “数据记录”选中已结束实验，打开实验查看界面。
2. 调整图表范围、页签或体积单位，点击“导出此实验包”，保存 `.phcexp`。
3. 把文件复制到另一台电脑，在“数据记录 → 导入实验包并恢复界面”导入。

恢复该实验的参数快照、完整测量、曲线、注入量记录和查看状态。重复导入同一个包会打开已有记录。参数与任务只读，不改变本机校准、注射器余量或控制设置，不连接设备或执行注射。CSV、PNG 和软件更新 ZIP 不是实验包。

完整说明与第三方许可随安装包提供。软件验证与实际出液精度分别验收。
