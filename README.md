# PH Cond Pump — Windows 便携版

pH、电导率与有限剂量注射泵控制工作台，中文界面。

**[下载最新正式版](https://github.com/Xin-coding/ph-cond-pump-releases/releases/latest)**

在 Releases 的 Assets 中下载 `PHCondPump-版本号-windows-x64.zip`。完整解压后运行 `PHCondPump.exe`，无需另装 Python，也无需登录 GitHub。不要下载 GitHub 自动生成的 “Source code” ZIP，那只是这个说明仓库。

本仓库只发布编译程序、使用说明和模拟示例；开发源码仓库保持私有。安装包不包含实验数据、个人校准或运行配置。程序不会上传实验数据或设备信息。

## 首次升级到支持在线更新的版本

1. 在旧软件中结束实验，确认泵停止并断开，关闭软件。
2. 将新安装包解压到新的可写文件夹，保留旧文件夹。
3. 运行新文件夹中的 `PHCondPump.exe`。默认沿用当前 Windows 用户桌面 `PH-Cond-Pump/data` 中的历史数据；如设置过 `PHCOND_HOME`，继续使用原设置。
4. 在“版本与更新”核对程序与数据目录。1.2.0 起可在软件内检查、下载和安装后续版本，也支持导入离线 ZIP。

## 更新与回退

下载可随时进行；安装和回退要求实验结束、泵停止并断开。安装包经过发布签名和逐文件校验。更新器先备份程序和数据，用数据库副本检查新版启动，然后替换程序并重启。

回退仅切换程序，保留当前实验记录、注射器余量和校准；数据库不兼容时阻止回退。v1.1 及更早版本保留手动备份，不提供界面一键回退。重启不会自动连接设备或恢复加液。

详细说明和第三方许可随安装包提供。软件测试通过与实际出液精度需分别验收。
